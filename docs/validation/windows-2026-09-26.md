## Win32 + Engine 实窗检查

使用实际 Backend 和 Engine，不模拟原生窗口操作。测试把枚举结果限定到创建的 fixture PID，并在执行每个动作前检查窗口 ID 的范围。

验证了：

- 暂停时只观察；启用后调整列宽、合并堆叠、切换浮动。
- 切至空页后三个窗口可恢复地最小化；枚举仍保留窗口身份和 manager-minimized 状态。
- 将真实 iconic 坐标重新送入布局后，切回能恢复浮动窗口的正常矩形。
- 布局全屏及退出全屏；原生部分裁剪动作成功执行。
- 跨显示器移动，读回目标 monitor ID、实际矩形及视口包含关系。
- Disable 及显式 restore 后，三窗位置、大小、最小化状态恢复。
- 正常关闭一个窗口后，旧窗口 ID 的 Focus 请求返回 WindowGone；未强制测试 HWND 数值复用。

### 现场限制与修正

- `Ctrl+Alt+L` 和 `Ctrl+Alt+R` 在本机被其他程序占用，注册失败已显示。不能把对应默认快捷键记为通过；向右聚焦/列宽功能仍有命令面板入口；本次通过面板实测了列宽与指定窗口聚焦。其他已注册组合仍可工作。
- Orca 桌面工具曾把 100% 屏上的 `x=3840` 报为 `5760`，截图落到屏幕外，焦点操作也不稳定。后续使用 Win32 物理坐标、实际键盘输入和 WebView2 调试接口完成验证，没有将工具失败视为应用成功。
- GUI 检查发现并修复了原生阴影导致控制栏外框大于预留区域、概览被置顶控制栏覆盖、命令面板长错误导致外层滚动三个问题。

两条只读评审分别检查原生/布局与 UI/IPC。既有发现已修复并复核：浮动 iconic 恢复、运行时能力同步、应用级退出握手、退出错误可见、无恢复所有权时正常退出、X11 实例身份、多显示器弹层上下文、暂停时关闭面板及 Promise rejection。
