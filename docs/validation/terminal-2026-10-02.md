### Git Bash 首字丢失：未解决

宿主独立真实 PTY 回归仍失败。单次完整 `printf` 写入和分段 `p`、`rintf` 写入均可能在调整尺寸后被 Bash 执行为 `rintf`。记录传给 node-pty 输入 socket.write 的十六进制参数确认 `printf` 全部字节已交给该 JavaScript 调用；记录点在原始 write 调用之前，未记录异步写完成或原生输入记录。两条失败记录均没有自动查询回复。丢失位于该观测边界之后，具体 pipe、backend、console、MSYS 或 readline 层仍需跟踪；不能用前端修复宣称此问题已解决。
