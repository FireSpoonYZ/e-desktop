# e-desktop 桌面端方向

状态：用户已授权实现；已建立最小可构建工程与共享契约，真实窗口布局和平台适配仍待组件线实现及主持代理集成。不能将基线编译通过等同原生能力完成。

- Rust + Tauri 2 跨平台，当前构建主机 Windows；Windows Win32、Linux X11、macOS AX 独立适配。Wayland 未接入时明确不支持，AX 未授权时明确提示；不宣称三平台能力相同。
- 尽量接近 niri 的真实应用窗口体验：横向滚动列、列内纵向堆叠、纵向页面、焦点跟随、移动/宽度/浮动/布局全屏、键盘操作。页面不是项目、任务或系统虚拟桌面。
- 日常窄顶栏与窄页栏是独立原生 WebviewWindow，其他应用占剩余区域；概览与命令窗口仅调用时展示，不用全屏网页冒充窗口管理器。
- 初始暂停；用户显式启动平铺。接管前保存原窗口状态，停用/正常退出还原；离屏窗口使用可恢复最小化，不结束进程代替关闭。异常退出不能承诺自动恢复。
- 深石墨 #191b1c、表面 #232627、暖白文本、灰绿焦点 #a8cbb9，系统 sans 与等宽快捷键，细边框、圆角不超过 8px。没有营销 hero、任务卡、AI 聊天。
- Orca 仅参考未来手机远程体验；当前不做手机、网络、隧道、账户、项目/任务或 LLM。

共享类型、平台方法、组件 props 与各 lane 目录以 [implementation-contract.md](../implementation-contract.md) 为准。公共契约及 App/bridge/app 接线由主持代理维护。组件 worker 不操纵真实桌面或浏览器。

Windows 裁剪与鼠标命中、多屏负坐标/混合 DPI、弹窗/IME、焦点限制、快捷键冲突、最小化保留与退出还原均需主持代理实机验证。Linux/macOS 需独立构建、权限与真实窗口验证；视觉稿和代码存在都不是支持证据。
